# Удача — это тоже суперспособность

Веб-приложение для ежедневного броска монетки с лидербордом и публичной лентой результатов.

## Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Prisma** + **PostgreSQL**
- **Framer Motion** (анимации)
- **SWR** (кеширование данных)
- **Zod** (валидация)

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Заполните `DATABASE_URL` вашей строкой подключения к PostgreSQL.

### 3. Инициализация базы данных

```bash
# Генерация Prisma Client
npm run db:generate

# Применение схемы к базе данных
npm run db:push
```

### 4. Запуск приложения

```bash
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## Особенности

### 🎨 Дизайн 2025

- Глубокая тёмная тема (#0A0A1A)
- Золотые акценты для победителей
- Плавные анимации с Framer Motion
- Адаптивный дизайн для всех устройств

### 🎲 Честная генерация

- Серверная генерация результата через `crypto.randomInt`
- Дополнительная случайность через SHA256 хеш
- Прозрачность: каждый бросок логируется с nonce и hash
- Защита от повторных бросков (1 раз в день)

### 📊 Функции

- **Ежедневный бросок**: один бросок в день
- **Серии**: только орёл увеличивает серию
- **Лидерборд**: топ игроков по максимальной серии
- **Публичная лента**: последние 20 бросков
- **Статистика**: общая статистика проекта
- **Проверка честности**: возможность проверить результат по nonce

### 🎵 Звуки

Поместите звуковые файлы в `public/sounds/`:
- `heads.mp3` - звук для орла
- `tails.mp3` - звук для решки
- `win.mp3` - звук для нового рекорда
- `toss.mp3` - звук броска монетки
